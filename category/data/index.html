JSON, CSV and YAML

Structured data fails loudly: one trailing comma and the whole document is invalid. These tools parse strictly, report the position of the first error, and never silently repair what they were given.

01 JSON Formatter & Validator Parse JSON strictly, see exactly where it breaks, and print it with consistent indentation. JSON.parse → 02 JSON Minifier Strip every optional byte from JSON without changing what it means. JSON.parse → 03 JSON Diff Compare two JSON documents structurally and list every added, removed and changed path. Recursive structural diff → 04 JSON ↔ CSV Converter Convert arrays of objects to CSV and back, with the flattening rules stated up front. RFC 4180 quoting → 05 JSON ↔ YAML Converter Convert between JSON and YAML with a real parser, not a regex. yaml →

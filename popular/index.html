Editor's shelf

Where most sessions start

This order is editorial, not measured. ParseFrame ships no third-party analytics, so a “trending” ranking would be invented data. Aggregate counts are kept in your own browser and never transmitted.

  1. 01 JSON Formatter & Validator The first thing anyone needs when a payload is unreadable and the error message is useless. JSON.parse
  2. 02 JWT Decoder & Inspector Because a token's claims are readable by anyone, and the expiry is usually the bug. Base64URL
  3. 03 Regex Tester Patterns fail in ways that need a real subject string, not a mental model. RegExp
  4. 04 Base64 Encode / Decode Encoding and decoding, with the UTF-8 handling most tools get wrong. TextEncoder
  5. 05 UUID / ULID Generator Two kinds of identifier: random, and sortable by creation time. crypto.randomUUID
  6. 06 JSON ↔ CSV Converter Two-way conversion with explicit nesting rules. RFC 4180 quoting
  7. 07 JSON ↔ YAML Converter Round-trip conversion that respects YAML anchors and quoting. yaml
  8. 08 SHA Hash Generator A checksum you can compare against a published value. crypto.subtle.digest

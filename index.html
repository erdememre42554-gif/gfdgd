    01 / Readability

    The same bytes, arranged so a human can see the shape

    Formatting changes nothing about the data. It changes whether you can spot that roles is an array and active is a boolean instead of the string “true”. 

    {"id":42,"tags":["a","b"],"active":true}
    →
    {
  "id": 42,
  "tags": ["a", "b"],
  "active": true
}

    02 / Validation

    An error you can act on, not a shrug

    “Unexpected token” with no position is a riddle. Every parser on this site reports the offset it gave up at, converted into a line and column you can jump to.

    Open JSON Formatter →
    parse · strictinvalid
    1{
2  "name": "Ada",
3  "roles": ["admin", "dev"],
4  "active": true,← trailing comma
5}

    Unexpected token } — line 5, column 1

    03 / Transform

    One structure, three notations

    JSON, YAML and CSV describe the same table. The conversion is a parse and a re-serialise — never a regex.

    json

    [
  { "id": 1, "city": "Izmir" },
  { "id": 2, "city": "Bonn" }
]
    →

    yaml

    - id: 1
  city: Izmir
- id: 2
  city: Bonn
    →

    csv

    id,city
1,Izmir
2,Bonn

    conversions run in the tab · no schema inference · comments are lost by design

    06 / Difference

    Two files in, one honest list of changes out

    Line diffs are for text. Structured diffs are for data: a reordered key is not a change, but a moved array element is, because position is part of an array's value.

    left

    {
  "plan": "pro",
  "seats": 3,
  "beta": false
}

    structural diff

    • changed $.seats 3 → 5
    • added $.renewal "2027-01-01"
    • removed $.beta

    07 / Evidence

    Behaviour is documented, not vibes

    Training articles cite the specification that actually defines the behaviour.

    • RFC 8259

      JSON data interchange format — the strict grammar this site validates against.

    • WHATWG URL

      Percent-encoding rules, and why a space is %20 in a path but + in a query.

    • RFC 7519

      JWT claims: exp, iat, nbf, aud, iss — and why encoding is not secrecy.

    • WCAG 2.2

      Contrast ratio formula and the 4.5:1 / 3:1 thresholds.

    • RFC 9562

      UUID versions, including v4's 122 random bits.

    • YAML 1.2

      Core schema, and why “no” is a boolean in 1.1 but a string in 1.2.

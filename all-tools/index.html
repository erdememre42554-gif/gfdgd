How to read this table

“Runs with” names the actual browser primitives and libraries the tool uses. If a tool needed a server, it would be listed here as a network call — none of the twenty do. The six categories exist because structured data, text, encodings, identifiers, schedules and contrast fail in different ways, not because the marketing wanted more columns.

  • JSON, CSV and YAML — Format, validate, diff and convert structured data. Parsing happens in the tab, so a payload with customer records never leaves your machine.
  • Text, markup and patterns — Diff, regex, Markdown, HTML, CSS and SQL — the tools you reach for when something is almost right.
  • Encoded payloads — Base64, percent-encoding and JWT inspection, with the difference between decoding and verifying made explicit.
  • Identifiers and digests — UUIDs, ULIDs, SHA digests and HMACs computed with Web Crypto inside the tab.
  • Time and schedules — Unix timestamps and cron expressions, with timezone behaviour stated rather than assumed.
  • Contrast and colour — WCAG contrast ratios computed from the actual formula, with AA and AAA thresholds by text size.
